# Execution Plan — Enterprise OT Management Portal Full-Stack Audit & Polish

## Overview
Decompose the project into sequential/parallel engineering milestones addressing all four core requirements:
- R1: Calm Editorial Visual Integrity (#0E3A66, #17538F, #2E90CB, #DCE4EA, #F3F6F8, #333B41), 11 views/modals/drawers/dialogs, typography, mobile/tablet/desktop responsive stickiness.
- R2: Virtualization for 100+ employees x 31 days with 60fps scrolling, client calculation caching, and instantaneous cell interactions.
- R3: Shift calculation engine accuracy (M8/A8/N8, M12/A12/N12, 16h/24h shifts, split overnight shifts, holiday multipliers 1.5x/3.0x/1.0x, 36h OT limit & 6-consecutive-day fatigue rules).
- R4: Export/Import (CSV/Excel), PWA offline shell (Service Worker caching, manifest, field device installability), and zero-error TypeScript build (`npm run build`).

## Phases
1. **Phase 0: Multi-Track Survey (3 Explorers)**
   - Explorer 1: UI/UX, Design System (#0E3A66 etc.), 11 views, responsive/mobile layout audit.
   - Explorer 2: Calculation Engine, Shift rules, overtime limits, holiday multipliers, fatigue alerts.
   - Explorer 3: Grid Virtualization, state management, PWA Service Worker, Excel/CSV Export/Import, build system.
2. **Phase 1: Milestone Definition & PROJECT.md Generation**
   - Synthesize survey findings into Feature Inventory and Milestones.
3. **Phase 2: Milestone Implementation Cycles (Worker -> Reviewers -> Challengers -> Auditor -> Gate)**
   - M1: Calculation Engine & Rule Validation
   - M2: Grid Virtualization & Performance
   - M3: Visual Design & Responsive Mobile Polish
   - M4: PWA, Export/Import & Offline Capability
4. **Phase 3: Integration & End-to-End Adversarial Verification**
   - Challenger & Auditor verification across all requirements.
5. **Phase 4: Final Synthesis & Sentinel Reporting**
